## 自动检查

使用解包后的 Ubuntu Python 3.12 / PyQt 6 运行以下命令，7 项检查通过：

```bash
AIMO_BUILD_DIR=/path/to/build QT_QPA_PLATFORM=offscreen \
  bash scripts/native_env.sh /path/to/build/sysroot/usr/bin/python3.12 \
  -m unittest discover -s tests -v
```

涵盖文件名边界、回收站冲突和还原、计算器执行边界、偏好持久化、
预览账户密码隔离，以及 120 个中文文件的异步加载、主题切换和反复关窗，
还有带动画窗口打开时确认退出登录的事件循环回归检查。
这项回归检查能重现原先被关窗动画阻止退出的问题，修订后通过。
原生测试会在没有 PyQt 6 的主机上跳过；仅使用主机 Python 运行通过，
不能替代这项 Qt 检查。预览账户检查与上表的真实 Linux 账户验证分别完成。
