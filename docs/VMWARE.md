# AimoOS 0.2.0：Windows VMware 手把手部署

适用：Windows 上的 VMware Workstation 16.2 / 17 或更新版本。虚拟硬件版本为 19，使用 **BIOS**；本版不支持 UEFI / Secure Boot 安装。

当前是预览版 Linux 系统，包含中文 AimoOS 桌面、LibreOffice、中文输入、浏览器和真实 Linux 用户。Windows `.exe` 不属于本版支持范围。

## 先准备

- 建议 Windows 主机有 8 GB 以上内存，留出至少 10 GB 空间；ISO 新建虚拟机建议预留 25 GB。
- 虚拟机分配 4 GB 内存、2–4 个 CPU，使用 NAT 网络，**关闭“加速 3D 图形”**。
- 两种方法选择一种即可。第一次建议直接打开虚拟机包，步骤最少。
- 下载 `AimoOS-0.2.0-VMware.zip` 或 `AimoOS-0.2.0-amd64.iso`。不要把 ZIP 直接交给 VMware，需要先解压。
- 若仓库是私有的，GitHub Release 下载需要登录具有该仓库访问权限的 GitHub 账户。

## 方法一：直接打开虚拟机包（推荐）

1. 下载 `AimoOS-0.2.0-VMware.zip`，在 Windows 资源管理器右键 → **全部解压缩**。建议解压到 `D:\VMs\AimoOS`；不要在压缩包内部打开文件。
2. 确认文件夹中同时有 `AimoOS.vmx` 和 `AimoOS.vmdk`，两者必须保存在同一文件夹。
3. 启动 VMware Workstation → **文件 → 打开**（或首页“打开虚拟机”）。选择解压得到的 `AimoOS.vmx`。
4. 在“编辑虚拟机设置”检查内存 4096 MB、处理器 2–4 个、网络适配器 **NAT**、显示器 **不勾选加速 3D 图形**。磁盘容量为 20 GB，按实际内容占用主机空间。
5. 点击 **开启此虚拟机**。如果 VMware 问“已移动”还是“已复制”，选择 **我已复制该虚拟机**。如果提示旧虚拟硬件版本，可保留原版本，不必升级。
6. 等待进入“设置你的账户”。首次启动会初始化中文字体与语言，可能比后续启动慢。
7. 填写显示名称、用户名、密码和确认密码。用户名使用小写英文字母开头，可包含数字和下划线。点击 **创建账户**。没有预设密码。
8. 进入桌面后点击居中的开始菜单，打开文件、浏览器、设置或 LibreOffice。中文输入可以用 `Ctrl+空格` 切换。
9. 结束使用时通过开始菜单关闭系统。下一次在 VMware 开机、输入自己设置的密码即可；文件和设置保存在虚拟磁盘中。

## 方法二：使用 ISO 新建并安装

1. 下载 `AimoOS-0.2.0-amd64.iso`。ISO 保持为文件，不需要解压、刻录或复制到 U 盘。
2. VMware → **文件 → 新建虚拟机** → 选择 **自定义（高级）**。
3. 硬件兼容性选择 Workstation 16.2 或更新版本。安装来源选择 **稍后安装操作系统**，避免 VMware 的自动“简易安装”。
4. 客户机操作系统选择 **Linux → Ubuntu 64 位**。名称填写 `AimoOS`，选择保存文件夹。
5. 固件类型选 **BIOS**。如果向导未出现这一项，创建完成后在“虚拟机设置 → 选项 → 高级”检查固件类型为 BIOS。
6. 处理器设置为 1 个处理器 × 2 或 4 个核心，内存 **4096 MB**，网络选 **NAT**。
7. 磁盘控制器可保留推荐值，但在“虚拟磁盘类型”页选择 **SATA**；创建一个全新的 **20 GB 或更大**虚拟磁盘。选择拆分或单文件均可，不要关联装有数据的磁盘。
8. 完成向导，不立即开机。打开“编辑虚拟机设置” → **CD/DVD** → “使用 ISO 映像文件”，选择下载的 ISO，勾选 **连接 / 启动时连接**。显示器中取消 **加速 3D 图形**。
9. 开机。若没有从光盘启动，关机后选择 **虚拟机 → 电源 → 开机时进入固件**，在 BIOS 的 Boot 页把 CD-ROM 放在硬盘之前，再保存启动。
10. 等待中文“安装 AimoOS”界面。列表应显示刚新建的空白磁盘，例如 `/dev/sda · 20 GB`。安装器不会列出已有分区或文件系统的磁盘。
11. 核对所选虚拟磁盘，输入 **INSTALL**（全大写），点击 **开始安装**。等待复制系统和安装启动程序，期间不要强制关闭虚拟机。
12. 看到“安装完成”后，点击 **关闭虚拟机**。
13. VMware → “编辑虚拟机设置 → CD/DVD”，取消 **连接 / 启动时连接**，或改为不加载 ISO。这一步防止再次进入安装器。
14. 再次开机，从虚拟硬盘启动。进入“设置你的账户”，按方法一的第 7–9 步完成账户设置和日常使用。

## 常见问题

- **又进入安装界面**：关机后断开 ISO，再开机。
- **EFI Network / No operating system / 黑屏**：检查固件为 BIOS、磁盘连接正常、3D 加速关闭；ISO 方法还需要完成实际安装。
- **没有可安装磁盘**：磁盘要至少 16 GB，且完全空白。新建一个 20 GB SATA 虚拟磁盘再启动；本版安装器不处理已有分区磁盘。
- **鼠标被虚拟机捕获**：按 `Ctrl+Alt` 释放鼠标；按 `Ctrl+Alt+Enter` 切换全屏。
- **没有网络**：检查 VMware 的 NAT 网络和“启动时连接”；系统通过 DHCP 获取地址与 DNS。
- **字体初始化或应用启动较慢**：首次开机和软件渲染会增加等待时间。关闭不需要的应用，主机允许时分配更多 CPU。不要为此开启本版尚未验证的 3D 加速。
- **复制粘贴 / 自动分辨率没有响应**：已集成 open-vm-tools，但这些 VMware 主机集成功能尚未在真实 Windows VMware 上验证，不应作为当前版保证。
- **想重新开始**：关机后保留原虚拟机作备份，再把原始 ZIP 解压到另一个文件夹。不要覆盖含有自己文件的 VMDK。

## 校验下载

PowerShell 在下载目录运行：

```powershell
Get-FileHash .\AimoOS-0.2.0-amd64.iso -Algorithm SHA256
Get-FileHash .\AimoOS-0.2.0-VMware.zip -Algorithm SHA256
```

与同一发布中的 `SHA256SUMS.txt` 比较。

## 构建者记录

镜像通过 BIOS + SATA 引导测试验证，采用真正的 Linux / Qt 桌面。当前构建环境不能运行 Windows VMware，因此提供的是相同启动路径和虚拟设备下的 QEMU 验证，不宣称已经在真实 VMware Workstation 上实测。日常办公兼容性与长期稳定性仍需要使用反馈。
